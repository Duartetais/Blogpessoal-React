# 📰 Blog Pessoal - React

Projeto desenvolvido com fins acadêmicos, com o objetivo de aplicar na prática conceitos modernos de desenvolvimento front-end utilizando **React** e **TypeScript**.

A aplicação simula a estrutura de um blog pessoal, com organização baseada em **componentização**, **separação de responsabilidades** e **boas práticas de código**.

---

## 🎓 Contexto acadêmico

Este projeto foi desenvolvido como parte do processo de formação em desenvolvimento web, com foco em:

* Estruturação de aplicações React
* Uso de TypeScript para tipagem segura
* Organização de código escalável
* Criação de componentes reutilizáveis

---

## ▶️ Como executar o projeto

### 1. Clone o repositório

```bash id="qv6h0k"
git clone https://github.com/Duartetais/blog-pessoal-react.git
```

### 2. Acesse a pasta do projeto

```bash id="5l0ptk"
cd blog-pessoal-react
```

### 3. Instale as dependências

```bash id="i0v5f6"
npm install
```

### 4. Execute a aplicação

```bash id="cz7f5l"
npm run dev
```
